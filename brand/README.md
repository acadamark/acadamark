# Enscribe brand assets

The canonical Enscribe brand marks. The three SVGs are the **masters**; the rasters
are **frozen derivatives** generated from `enscribe-favicon.svg`.

## Masters (edit these)

| File | Master for |
|------|-----------|
| `enscribe-favicon.svg` | The favicon / app-icon mark — the source every raster below is generated from. |
| `enscribe-mark-full.svg` | The full logo mark (icon at display size, more detail than the favicon). |
| `enscribe-wordmark.svg` | The "Enscribe" wordmark (logotype) — for a header/lockup, not currently used on the site. |

## Frozen raster derivatives (do not hand-edit)

| File | Size | Generated from |
|------|------|----------------|
| `favicon.ico` | 16 / 32 / 48 (multi-res) | `enscribe-favicon.svg` |
| `apple-touch-icon.png` | 180×180 | `enscribe-favicon.svg` |
| `icon-512.png` | 512×512 (also the social/OpenGraph image) | `enscribe-favicon.svg` |

`favicon_16.png` / `favicon_32.png` are intentionally **not** committed — those sizes
live inside `favicon.ico`.

## The standing rule — these rasters are a documented freeze, not a guarded artifact

The rasters are committed as-is and are **not** regenerated by any build step or checked
by any freshness guard. If the mark ever changes, edit `enscribe-favicon.svg` and
**regenerate the rasters by hand** (any SVG→ICO/PNG tool), then update **both** this
directory and the site's shipped copy in [`../docs-source/assets/`](../docs-source/assets/)
(`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-512.png` — the set the static
site build copies into `site/assets/` and the page `<head>` links). This directory is the
archival master set; `docs-source/assets/` is the deployed copy. Keeping them in step is a
manual step by design — a deliberate freeze, recorded here so it is not mistaken for drift.
