# `<section-title>`

The section title of a `<section>`. Auto-generated by the structural plugin from the pipe-content of `<section | ...>` (title extraction); an explicit-form escape hatch exists but is not the authoring path.

The element is a custom eHTML element (not HTML-native). Its content is inline prose — text plus inline elements (emphasis, citations, cross-references, math, etc.).
