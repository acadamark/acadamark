# @enscribejs/jats-export

JATS XML export for [enscribe](https://github.com/enscribejs/enscribe).

Consumes the structured mdast tree produced by `@enscribejs/interpreter`'s
structural plugins and emits JATS (Journal Archiving and Interchange Tag Set)
and BITS (Book Interchange Tag Set) XML. Node-only.

```sh
npm install @enscribejs/jats-export
```
