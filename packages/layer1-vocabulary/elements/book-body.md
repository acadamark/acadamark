# `<book-body>`

The body region of a `<book>`. Auto-generated by the structural plugin when authors omit explicit region wrappers; rarely authored directly. The explicit form is available when authors need fine control over which children belong in which region.

Body content: paragraphs, sections, figures, asides, blockquotes, tables, lists.
