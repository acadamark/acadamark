# `<section-subtitle>`

The section subtitle of a `<section>`. Auto-generated by the structural plugin from the pipe-content of `<section | ...>` (title extraction); rarely authored directly. The explicit form is available as an alternate authoring path.

The element is a custom Layer 1 element (not HTML-native). Its content is inline prose — text plus inline elements (emphasis, citations, cross-references, math, etc.).
