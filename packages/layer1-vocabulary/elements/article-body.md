# `<article-body>`

The body region of an `<article>`. Generated by `acadamarkArticleStructuring` to hold the article's main content. Rarely authored directly.

## Contents

The structural plugin places everything that is neither metadata (`<meta>`) nor back-matter (bibliography, note-list) into `<article-body>`:

- Sections, sub-sections, sub-sub-sections.
- Paragraphs (`<p>`, or implicit paragraphs from markdown blank-line separation).
- Figures, asides, blockquotes.
- Tables, lists (`<ul>`, `<ol>`).
- Block-level content from DSL engines (math display, code blocks, etc.).

The classification matches the `block` and `section` shape tokens (see `notes/shape-tokens.md`).
