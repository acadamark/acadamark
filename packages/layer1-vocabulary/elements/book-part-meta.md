# `<book-part-meta>`

Descriptive metadata for a `<book-part>` (chapter, part, appendix, etc.). Auto-generated by the structural plugin when a book-part has pipe-supplied or `<meta>`-supplied descriptive content; rarely authored directly. Maps to JATS `<book-part-meta>`.
