# `<book-front>`

The front-matter region of a `<book>`. Generated by `enscribeBookStructuring` from the author's `<meta type=book>` declaration. Rarely authored directly.

## Contents

The structural plugin places these children inside `<book-front>`:

- The original `<meta>` block, with its `<title>`/`<subtitle>` promoted to `<book-title>`/`<book-subtitle>`. `<meta>` itself survives in the output and holds the descriptive metadata.
- Book-parts with front-matter `book-part-type` values: `preface`, `foreword`, `dedication`.
- Any `<data>` or `<config>` blocks the author explicitly placed in front matter.

## Authoring

Authors rarely write `<book-front>` directly. The typical authoring path uses `<meta type=book>` and lets the structural plugin generate the region. The explicit form is available as an escape hatch.
