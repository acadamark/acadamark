# `<article-front>`

The front-matter region of an `<article>`. Generated by `enscribeArticleStructuring` from the author's `<meta type=article>` declaration (or by default when `<meta>` has no type). Rarely authored directly.

## Contents

The structural plugin places these children inside `<article-front>`:

- The original `<meta>` block, with its `<title>`/`<subtitle>` promoted to `<article-title>`/`<article-subtitle>`. `<meta>` itself survives in the output and holds the descriptive metadata (`<author>`, `<date>`, `<abstract>`, etc.).
- Any `<data>` or `<config>` blocks the author explicitly placed in front matter (the default location is back matter, but front-matter placement is allowed).

## Authoring

Authors rarely write `<article-front>` directly. The typical authoring path uses `<meta type=article>` and lets the structural plugin generate the region. The explicit form is available as an escape hatch when authors need full control:

```
<article>
  <article-front>
    <meta>
      <article-title | Custom Title>
      <author | ...>
    </meta>
  </article-front>
  <article-body>
    <section | Introduction>
    Content.
  </article-body>
</article>
```
