# `<article-front>`

The front-matter region of an `<article>`. Auto-generated by the structural plugin when authors omit explicit region wrappers; rarely authored directly. The explicit form is available when authors need fine control over which children belong in which region.

Front-matter children: title/subtitle, metadata (`<meta>`), and other introductory block content.
